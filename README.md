# niri_noctalia

My Niri Wayland compositor configuration (and related dotfiles), managed in `~/.config`.

## Showcase

[![Watch the showcase video](https://img.youtube.com/vi/VIDEO_ID/maxresdefault.jpg)](https://www.youtube.com/watch?v=VIDEO_ID)

Replace `VIDEO_ID` with your YouTube/Vimeo ID if you want to embed a specific video. If you have the raw video in the repo (e.g., `assets/showcase.mp4`), you can also link to it locally.

## What's included

- `niri/` - Niri compositor config
- `nvim/` - LazyVim Neovim configuration
- `waybar/` - Waybar status bar
- `kitty/` - Kitty terminal
- `mako/` - Notification daemon
- `swaylock/` - Screen locker
- `rofi/` - Application launcher
- `hyprpaper/` - Wallpaper manager
- `opencode/` - OpenCode AI assistant config
- Various other utility configs

## Installation

Clone the repo to `~/.config`:

```bash
git clone git@github.com:SAB1825/niri_noctalia.git ~/.config
```

Note: This repo tracks files directly (no submodules). If you had a nested nvim git repo before, it's been flattened into the root.
